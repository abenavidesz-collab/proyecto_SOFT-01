# Misión Órbita

## Descripción del proyecto

Misión Órbita es un sistema de software desarrollado en Python para asistir a agencias espaciales en la planificación, cálculo de recursos, verificación de insumos esenciales (combustible, oxígeno, energía y provisiones) y autorización formal de lanzamientos espaciales mediante lógica algorítmica secuencial y condicional.

## Objetivo del proyecto

Automatizar la evaluación del soporte vital y energético de misiones espaciales para garantizar el cumplimiento estricto de las reservas de emergencia y criterios de seguridad preestablecidos antes de autorizar cualquier despegue.

## Funcionalidades incluidas

- **Cálculo de recursos para una misión (`ejercicio1_recursos.py`):** Estimación secuencial de combustible (ida, regreso y reserva), oxígeno, energía y provisiones según la tripulación y días de viaje.
- **Verificación de combustible (`ejercicio2_combustible.py`):** Evaluación condicional del combustible disponible frente a los requerimientos de misión y reservas, emitiendo alertas en caso de bajo margen.
- **Verificación del soporte para la tripulación (`ejercicio3_verificacion.py`):** Comprobación del cumplimiento simultáneo de límites mínimos de oxígeno y provisiones.
- **Autorización general de la misión (`ejercicio4_autorizacion.py`):** Evaluación integral de todos los factores (combustible, oxígeno, energía y provisiones) para otorgar o denegar el permiso de lanzamiento.
